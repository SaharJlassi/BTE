Déroulement de l'import
1
Choix du type Le format des colonnes diffère selon la nature des données. Le type sélectionné doit correspondre au fichier envoyé.
2
Choix de l'année L'année n'est jamais déduite du nom du fichier : elle est sélectionnée manuellement pour éviter toute erreur d'affectation.
3
Répartition par agence {% if profil.est_super_admin %} Chaque ligne est dirigée vers son agence d'origine grâce au code figurant dans la colonne COD_UG. {% else %} Seules les lignes portant le code de votre agence ({{ profil.agence.code_agence }}) sont retenues ; les autres sont écartées. {% endif %}
4
Contrôle des doublons Une agence disposant déjà de données pour l'année choisie est ignorée. Les autres agences du fichier sont importées normalement.
